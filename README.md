# Mai Kou Yang — Software Systems Portfolio

## Project Description

This project is a personal student portfolio website created for my Software Systems course at Western Technical College.

The purpose of this website is to introduce myself, showcase what I am learning, and organize important notes and concepts from class.

Throughout the course, I will continue improving this website as I develop my skills in web development and software systems.

## Website Sections

### About Me
Introduces who I am, where I am studying, and my goal of becoming a software developer.

### What I'm Learning
Provides an overview of the technologies and concepts I am studying, including HTML, CSS, JavaScript, Git, and GitHub.

### Course Notes
Contains notes about important concepts learned in class, including computer hardware, software, memory, storage devices, firmware, and web development.

Visitors can click the **View My Notes** button to display a different course note.

### Search My Notes
Allows visitors to search my course notes using keywords. Matching notes appear on the webpage, and visitors can clear their search results.

## Technologies Used

- **HTML:** Structures the content of the website.
- **CSS:** Styles the website, including its colors, layout, buttons, and responsive design.
- **JavaScript:** Adds interactive features such as displaying and searching course notes.
- **Git:** Tracks changes to the project.
- **GitHub:** Stores and manages the project repository.

## JavaScript Features

My website demonstrates the following JavaScript concepts:

- Variables using `let` and `const`
- Arrays for storing course notes
- Functions for organizing code
- `querySelector()` for selecting HTML elements
- Event listeners for button clicks and keyboard input
- Conditional statements using `if` and `else`
- DOM manipulation to update webpage content
- Array methods such as `filter()` and `forEach()`
